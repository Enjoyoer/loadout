# Skills catalog

Install packages flat under the target client's `skills` directory. Each name below is a separate active package.

| Category | Packages |
| --- | --- |
| Engineering | `codebase-design`, `domain-modeling`, `improve-codebase-architecture`, `uv-python` |
| Operations and integrations | `download-to-nas`, `gmail`, `google-sheets`, `recover-mouse-input`, `todoist-api`, `wizard` |
| Orchestration | `claude-cloud`, `dispatching-parallel-agents`, `handoff`, `opc`, `opn`, `personal-skills`, `repo-lessons` |
| Planning and writing | `grilling`, `sample` |
| Research and documentation | `find-docs`, `liteparse` |
| Web and browser | `browse-x`, `frontend-design`, `pake`, `playwright` |

Some packages require separate tools or service access. The repository contains no tokens, account configuration, private host inventory, or global agent instructions.
