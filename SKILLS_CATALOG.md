# Skills catalog

Install packages flat under the target client's `skills` directory. Each name below is a separate active package.

| Category | Packages |
| --- | --- |
| Engineering | `codebase-design`, `domain-modeling`, `improve-codebase-architecture`, `uv-python` |
| Operations and integrations | `recover-mouse-input`, `wizard` |
| Orchestration | `claude-cloud`, `dispatching-parallel-agents`, `handoff`, `opc`, `opn`, `personal-skills`, `reassign-pm`, `repo-lessons` |
| Planning and writing | `grilling`, `sample` |
| Research and documentation | `find-docs`, `liteparse` |
| Web and browser | `browse-x`, `frontend-design`, `pake`, `playwright` |

Some packages require separate tools or service access. Personal, account-bound, or credential-bearing skills are not published here; keep them in your private skill overlay (see `skills/orchestration/personal-skills/fleet/README.md`). The repository contains no tokens, account configuration, private host inventory, or global agent instructions.
