# Reassign PM

The current agent (`$PASEO_AGENT_ID`) becomes the project's PM. Use supported Paseo tools or CLI/API operations. Reassignment authorizes archiving the previous PM, not its workspace or unrelated agents.

1. **Discover globally.** Inspect self and list agents across all workspaces, including dormant PMs; do not use a cwd filter or a recent-only result as proof of absence. With CLI, use `paseo ls --global` and inspect candidates. If the owner supplied an old PM ID, inspect that exact agent. Otherwise resolve other unarchived `role=pm` agents by the supplied project label. Without a project, use workspace/project metadata and existing path equivalence to find the old PM, then inherit its `project` label; the current directory basename is the fallback. Expand home paths and compare realpaths where available. Missing paths or differing labels are unresolved evidence, not proof that there is no old PM. Stop on ambiguity; never choose the newest candidate automatically. If complete discovery finds none, continue without an archive.
2. **Read before waking.** Resume from root `STATUS.html` and `LESSONS.md` with `repo-lessons`, and inspect the old PM's saved activity. Request a live handoff only for information unavailable there and when the old PM has capacity. Lack of usage or quota must not block an otherwise verified takeover. Preserve unrelated checkout changes.
3. **Inventory retained agents.** Identify workers and watchers from actual parent relationships, explicit workstream assignments, and saved activity. Sharing a cwd is insufficient. Record each retained agent's Paseo ID, workspace ID, provider/native session ID, exact model, mode/thinking/features, role labels, cwd, and lifecycle state. Include assigned agents in other workspaces; leave unrelated and completed agents alone unless the owner says to retain them. Read each provider's model catalog and copy IDs verbatim, including Claude `[1m]` suffixes and OpenCode provider prefixes. Do not replace a model with a similar one when its ID is unavailable.
4. **Prepare placement.** Rename self's workspace to the basename of its directory. Retained agents already there need no move. For others, use a supported relocation operation only after checking it preserves the recorded identities, native history, settings, roles, and usable cwd. A parent label changes ownership, not workspace membership. Do not create replacement sessions, filesystem aliases, or edit daemon storage. If the installed version cannot safely relocate an agent, report the concrete native dependency in [references/native-relocation.md](references/native-relocation.md) and stop before role transfer or final archive. Do not archive workers merely to try importing them elsewhere.
5. **Transfer and verify.** Move retained agents to self's workspace and transfer their ownership through the supported parent operation; preserve unrelated labels. Set self's name to `<Project> PM`, its `role=pm` and `project` labels, and its exact catalog model ID, preserving its other settings. Inspect self and every retained agent: verify destination workspace, parent ownership, unchanged Paseo/native IDs and history, catalog model, settings, roles, usable cwd, and unarchived state. Resolve any extra active PM matches beyond self and the selected old PM before completing; do not silently retire a second candidate. On a failed check, stop before archiving and report any partial changes.
6. **Archive last.** Only after those checks, archive the selected old PM. Re-query globally: exactly one unarchived `role=pm/project=<name>` match must be self, and retained agents must remain unarchived in self's workspace. Archive the old workspace only when the owner explicitly requested it: re-inventory every remaining agent and terminal, verify retained agents are absent, and confirm the cascade is within that request. Never archive the replacement workspace. Local checkout files and native history must survive; stop if removing a managed worktree would violate that requirement.

Update the owned root memory under its local commit/ignore policy. Report the new PM ID/model, archived PM ID, retained-agent placement, any workspace archive, and unresolved dependencies. Then continue the assigned work.
